# Kids Edu Game Backend (FastAPI + Supabase)

Backend API phục vụ tựa game giáo dục cho trẻ em.
- Kết nối cơ sở dữ liệu Supabase (PostgreSQL).
- Cung cấp API lưu điểm, thú cưng và lịch sử học tập.
- Sẵn sàng tích hợp Speech-to-Text và AI Quiz Generator.
